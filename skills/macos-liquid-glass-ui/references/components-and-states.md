# 组件与状态

## 控件

按钮常规 `--lg-control-h-md`(40px)、主操作 `--lg-control-h-lg`(48px)、紧凑 `--lg-control-h-sm`(32px)；紧凑外观可扩展触控命中范围。输入 `--lg-input-h`(44px)，标签置顶。分段控件内边距 4px，选中白底轻阴影。开关视觉 `--lg-switch-w`×`--lg-switch-h`(36×22px)，标签也可点。表格行 `--lg-row-h`(48px，允许 44–52px)，数字右对齐并用 `.lg-num`，单位与精度一致。

表单默认单列，宽屏相关字段可并排。错误在字段附近，提交后聚焦错误摘要或第一处错误，不清空输入；异步校验防旧响应覆盖新值。只读可复制，禁用解释原因。提交防重复，失败保留输入。

## 弹层

模态常规宽 480–640px，max-width:calc(100vw - 32px)，max-height:min(80dvh,760px) 为起点。标题和按钮独立，正文滚动。短屏时**底栏进入正常流**（与 `references/layout-and-scroll.md` 的短屏口径一致），模态本身可用满高度，但不让操作按钮盖住最后一个字段。

抽屉 360–480px；不能挤坏主内容，空间不足覆盖显示。菜单自动翻转避边界，超过可见高度后内部滚动。菜单与模态的层级只用 `--lg-z-menu` / `--lg-z-modal`，模态内菜单优先 portal 进模态容器。

模态打开记录焦点、锁背景滚动并限制焦点；关闭恢复触发点与背景位置。Escape 关闭最高层，有未保存内容按业务规则处理。普通非模态 Popover 不强加焦点陷阱。

## 图表与画布

系列色用 `--lg-chart-1..5`，浅色与深色各一套（具体值与实测对比度见 `references/visual-system.md`）；主线 3px、辅助 2px，网格 `--lg-chart-grid`（浅色 #E7EEF5 / 深色 #2F343D，纯装饰、不承担 3:1），刻度 11–12px 起。主系列可用 18%→0 渐变面积，但不表示置信区间。

颜色不是唯一编码：每条系列同时给 marker 形状或 dash pattern（实线/虚线/点线），图例与 tooltip 都带同一标记，黑白打印与色觉障碍下仍可区分。阈值线、参考线属于"要参与读数"的图形，必须用 `--lg-border-strong` 或状态色并加文字标签，不能沿用装饰网格色。

Tooltip 高不透明白底（用 `--lg-surface`，不要半透明）、`--lg-radius-md`、`--lg-shadow-float`，不超视口；信息支持触摸和键盘获取。多图例可换行或用独立列表，不挤掉画布。深色主题必须验证网格与系列色两套值都生效，不要只换背景色。

监听真实容器尺寸，侧栏变化、隐藏→显示、全屏切换重新测量。零尺寸/未挂载不初始化，卸载清理实例及监听。

区分缺失和零值，不默认连断点。平滑、聚合、坐标截断需业务依据。刷新保持颜色、用户选择和可比坐标。

流程图默认适配，文字过小时提供缩放与居中。用户拖动后停止自动聚焦并提供回到当前节点。内容切换不改变外框与按钮区域。

## 状态

按组件需要覆盖默认、悬停、按下、焦点、选中、禁用、只读、加载、空态、错误、长内容、窄屏、短屏、减少动态/透明，不制造不适用状态。

- 初次加载：可预测结构用骨架；未知结构用简短进展。按钮内转圈可用，不强制全部骨架。
- 后台刷新：保留旧内容，不反复清空。
- 空态：无权限、无结果、尚未创建分别解释并提供下一步。
- 错误：局部错误不替换整页，重要错误不只靠 Toast。
- 部分成功：分别标出可用与未完成结果。
- 长等待：真实动作与时间，无可靠总量不用假百分比。
- 更新：保留焦点及滚动，aria-live 只播报摘要。

## 动效

悬停 `--lg-dur-hover`(150ms)；按下 `--lg-dur-press`(120ms)；选择 `--lg-dur-select`(200ms)；面板 `--lg-dur-panel`(240ms)；内容 `--lg-dur-content`(280ms)。easing `--lg-ease`：cubic-bezier(.2,.8,.2,1)，位移 4–8px，按压缩放约 .98。

减少动态时**只保留反馈类变化**（透明度、颜色、≤130ms 的边框变化），取消位移、缩放、视差与自动播放；状态仍然清晰。避免持续装饰循环、多层昂贵模糊；动效不能作为唯一完成提示。不要对字号、字距或圆角做动画。
