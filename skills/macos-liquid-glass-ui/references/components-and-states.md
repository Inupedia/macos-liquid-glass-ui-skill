# 组件与状态

## 控件

按钮常规 40px、主操作 48px、紧凑 32px；紧凑外观可扩展触控命中范围。输入 40–44px，标签置顶。分段控件内边距 4px，选中白底轻阴影。开关视觉 36×22px，标签也可点。表格行 44–52px，数字右对齐，单位与精度一致。

表单默认单列，宽屏相关字段可并排。错误在字段附近，提交后聚焦错误摘要或第一处错误，不清空输入；异步校验防旧响应覆盖新值。只读可复制，禁用解释原因。提交防重复，失败保留输入。

## 弹层

模态常规宽 480–640px，max-width:calc(100vw - 32px)，max-height:min(80dvh,760px) 为起点。标题和按钮独立，正文滚动。短屏可全屏。

抽屉 360–480px；不能挤坏主内容，空间不足覆盖显示。菜单自动翻转避边界，超过可见高度后内部滚动。

模态打开记录焦点、锁背景滚动并限制焦点；关闭恢复触发点与背景位置。Escape 关闭最高层，有未保存内容按业务规则处理。普通非模态 Popover 不强加焦点陷阱。

## 图表与画布

系列色 #1889EE/#47B8B0/#8E8BD4/#DCA45A/#D67C96；主线 3px、辅助 2px，网格 #E7EEF5 轻虚线，刻度 11–12px 起。主系列可用 18%→0 渐变面积，但不表示置信区间。

Tooltip 高不透明白底、14px 圆角、轻阴影，不超视口；信息支持触摸和键盘获取。多图例可换行或用独立列表，不挤掉画布。

监听真实容器尺寸，侧栏变化、隐藏→显示、全屏切换重新测量。零尺寸/未挂载不初始化，卸载清理实例及监听。

区分缺失和零值，不默认连断点。平滑、聚合、坐标截断需业务依据。刷新保持颜色、用户选择和可比坐标。

流程图默认适配，文字过小时提供缩放与居中。用户拖动后停止自动聚焦并提供回到当前节点。内容切换不改变外框与按钮区域。

## 状态

按组件需要覆盖默认、悬停、按下、焦点、选中、禁用、只读、加载、空态、错误、长内容、窄屏、短屏、减少动态/透明，不制造不适用状态。

- 初次加载：可预测结构用骨架；未知结构用简短进展。按钮内转圈可用，不强制全部骨架。
- 后台刷新：保留旧内容，不反复清空。
- 空态：无权限、无结果、尚未创建分别解释并提供下一步。
- 错误：局部错误不替换整页，重要错误不只靠 Toast。
- 部分成功：分别标出可用与未完成结果。
- 长等待：真实动作与时间，无可靠总量不用假百分比。
- 更新：保留焦点及滚动，aria-live 只播报摘要。

## 动效

悬停 120–160ms；按下 100–140ms；选择 180–220ms；面板 200–280ms；内容 240–320ms。easing:cubic-bezier(.2,.8,.2,1)，位移 4–8px，按压缩放约 .98。

减少动态取消非必要位移，状态仍清晰。避免持续装饰循环、多层昂贵模糊；动效不能作为唯一完成提示。
