# Liquid Glass Icon 验收清单

生成完成不等于设计通过。至少做以下检查。

## 1. 语义

- [ ] 不看产品名时，主对象仍能被描述出来。
- [ ] 主隐喻和产品核心用途有关，而不是通用“AI 星星 / 机器人 / 魔法棒”。
- [ ] 没有同时塞入多个互相竞争的概念。
- [ ] 如果基于现有品牌改造，历史识别元素仍然保留。

## 2. 小尺寸可读性

分别在 1024、256、64、32 px 心智或实际缩放检查：

- [ ] 1024 px：材质边缘干净，没有脏点、错误反射或局部畸变。
- [ ] 256 px：层级和主体清晰，不像普通插画。
- [ ] 64 px：主轮廓仍然稳定，辅助元素没有糊成噪声。
- [ ] 32 px：至少能识别主轮廓和核心色块。

如果必须放大才能理解，优先删细节，不要继续加锐化或高光。

## 3. Liquid Glass 材质

- [ ] 玻璃感服务于主体，不会让主体消失。
- [ ] 高光面积克制，没有形成大块白斑。
- [ ] 折射不会制造类似错误文字或杂乱纹理。
- [ ] 没有明显 chrome、镜面金属、果冻糖、塑料气囊感。
- [ ] 前后层关系明确，不靠无限叠加透明层制造复杂度。

## 4. 构图

- [ ] 主体居中且有安全留白。
- [ ] 没有设备 mockup、Dock、桌面场景或展示卡片混入最终图标。
- [ ] 没有文字、乱码、水印或伪品牌名。
- [ ] 没有过细的线、过小的洞或容易被圆角裁切的边缘主体。
- [ ] 图标看起来是 App Icon，而不是海报、产品摄影或完整 UI 截图。

## 5. 品牌与颜色

- [ ] 使用冻结的 HEX palette，没有明显跑色。
- [ ] 品牌主色仍占主导，而不是被生成模型替换成默认蓝紫渐变。
- [ ] 深浅背景下主体边缘仍有足够区分度。
- [ ] 同一 icon family 的材质、色温、视角、细节密度一致。

## 6. AI 图像常见错误

重点检查：

- [ ] 伪文字或类似字母的随机符号；
- [ ] 不对称但本应对称的结构；
- [ ] 错误透视、断裂边缘、悬空碎片；
- [ ] 多余按钮、开孔、把手、齿轮或无意义装饰；
- [ ] 边缘出现被裁断的残留元素；
- [ ] 同一材质在左右两侧表现完全不一致。

出现这些问题时优先使用图像编辑局部修正；如果核心结构已经错误，再重新生成。

## 7. Icon Composer 生产检查

如果图标要进入真实 Apple App 项目：

- [ ] 已提供清晰的 2–4 层 layer map；
- [ ] 生产源图没有预先烘焙平台圆角遮罩；
- [ ] 镜面、高光、折射、模糊、透明度和层间阴影可以在 Icon Composer 中重新控制；
- [ ] 能矢量化的主形状已计划重建为 SVG / vector；
- [ ] Default / Dark / Mono 外观有明确验证计划；
- [ ] 已说明最终效果需要在 Icon Composer / Xcode / 实际设备中验证。

## 8. 交付状态描述

只使用真实完成状态：

- `concept generated`：已生图，尚未小尺寸验收；
- `visual approved`：图像层面通过上述 QA；
- `production handoff prepared`：已有 layer map 和重建说明；
- `Icon Composer verified`：只有实际在 Icon Composer 中检查过才可以这样写；
- `Xcode/device verified`：只有真实运行验证过才可以这样写。

不要把一张 AI PNG 自动描述成“production-ready Apple icon”。
